# Неофициальный плагин SoundCloud для Spotube

[English](README.MD)

Плагин метаданных SoundCloud для [Spotube](https://spotube.cc)

## Сборка

```bash
LC_ALL=C.UTF-8 LANG=C.UTF-8 ./gradlew --no-configuration-cache --no-build-cache \
  clean :spotube_plugin_soundcloud:packageProductionPlugin
```
